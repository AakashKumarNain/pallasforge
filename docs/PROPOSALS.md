Please open an issue with the proposal name as soon as you start working on it. Also, we want to move fast. In case you do not have enough time to contribute in a healthy
manner, please avoid taking up the tasks. This does not mean that you need to contribute or work on a proposal daily, but we cannot wait on you
for a month or more to finish a kernel. Time is the real currency, even for OSS. If two people are working on the same thing, merge priority will be given to the one
finishing the entire thing first.

- Paged Attention
- Fused norm layers
- Mixture of Experts (MoE) layer
- Fused dequantization for different quantization schmes like w8a16
